# 家庭寻宝 Web App

这是一个可直接在 iPhone Safari 使用的 PWA。

## 最简单的使用方式

把整个文件夹放到一个支持静态网页托管的平台，然后在 iPhone Safari 打开网址。
Safari 分享 → “添加到主屏幕”，之后即可像 App 一样打开。

## 数据

所有寻宝数据保存在当前 iPhone 的 localStorage 中，不需要服务器数据库。

## 当前功能

- 房间地图
- 家具位置
- 藏宝点
- 找到后点击确认
- 总进度
- 房间完成
- 徽章
- 添加房间
- 添加宝藏
- PWA / 添加到主屏幕
- 基础离线缓存
